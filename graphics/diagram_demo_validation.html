Validation Flow:

This diagram shows the validation component of the RAG chatbot system, including how the Reasoning Model and Validator assess the chatbot’s accuracy.

  • Reasoning Model: Generates test questions to probe the chatbot's knowledge
  • Validator: Sends controlled queries and evaluates responses
  • Web Server: Interfaces with the chatbot
  • LLM: Receives feedback to improve output
